# Learning Rust Through Reimplementation

This repository is for learning Rust through small, complete projects.

Projects are written manually in Rust and then rewritten in TypeScript for side-by-side comparison. This makes differences in syntax, types, standard libraries, error handling, and tooling easier to understand while keeping my TypeScript skills active.

The Rust implementation always comes first. The TypeScript version initially reproduces the same project and may follow the structure established in Rust because it is written second. As my understanding grows, I expect the implementations to drift toward the idioms of their respective languages.

## Practice approach

The code is typed manually by me. I use documentation and AI to learn APIs, idioms, and trade-offs, but I write the actual implementation myself. The goal is to spend the hands-on time needed to build Rust knowledge.
