# Rock Paper Scissors - Odin

The Odin rewrite of the command-line Rock Paper Scissors game.

Requires [Odin](https://odin-lang.org/docs/install/).

```bash
odin run .
```

Play commands: `rock`/`r`, `paper`/`p`, and `scissors`/`s`.

Session commands: `stats`/`st` shows statistics and `quit`/`q` exits the game.
